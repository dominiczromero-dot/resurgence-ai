# Resurgence AI

> **New here? Follow START-HERE.md**: plain step-by-step setup on GitHub, free, no vidIQ.

A YouTube trend researcher and content strategist for **Call of Duty: Warzone Resurgence**. Open it in the morning and the first screen shows you:

> What's trending **today**, which creators are gaining views, and the **#1 video to make right now**.

Everything the app shows comes from the **YouTube Data API v3**. It ships with **no sample or demo data**: until research runs with your API key, every screen says "no verified research yet".

---

## 1. What's real and what's predicted

Every panel carries one of three labels:

| Label | Meaning | Examples |
|---|---|---|
| **Verified** | Returned by the YouTube Data API | views, likes, comments, upload dates, titles, links, thumbnails, subscriber counts |
| **Calculated** | Arithmetic on verified data | views per hour, channel baselines, breakout ratios, topic/weapon heat, momentum, competition |
| **Prediction** | Generated by Resurgence AI | video ideas, titles, thumbnail concepts, opportunity scores, "upload today / wait" verdicts |

**What YouTube doesn't give anyone:** other creators' impressions, click-through rate, audience retention and traffic sources. The app never uses or estimates these. (You can get them for **your own** channel through the YouTube Analytics API with OAuth. See "Extending" below.)

## 2. Connections needed

| Connection | Needed? | What it powers | Cost |
|---|---|---|---|
| **YouTube Data API v3 key** | **Required** | All verified data | Free, 10,000 quota units/day |

| GitHub (Actions + Pages) | Optional | Fully automatic morning research, dashboard on your phone | Free for public repos |
| OpenAI / Anthropic key | Not used | Possible extension for richer title wording | Paid per use |

### Get your YouTube API key (≈5 minutes)
1. Go to <https://console.cloud.google.com/> and create a project (e.g. "resurgence-ai").
2. **APIs & Services → Library**, search **YouTube Data API v3**, then **Enable**.
3. **APIs & Services → Credentials → Create credentials → API key**.
4. Open the key, set **API restrictions → Restrict key → YouTube Data API v3**, then save.
   Don't add *website* restrictions: the daily script sends no referrer, so it would be blocked.
5. Keep the key private. Don't commit it to Git. Use `.env` or a GitHub secret.

## 3. Run it

### Option A: open the file (quickest)
Double-click `index.html`, go to **Settings & data**, paste your key, press **Test**, then **Run research now**.

### Option B: local server (recommended)
```bash
npm start            # → http://localhost:5173
```
Served this way, the dashboard also **loads the daily script's results automatically** (`data/latest.json`, `data/history.json`), so research done overnight is waiting for you.

### First run checklist
1. **Competitors**: your list starts with `@devised_, @klawYT, @Lionxo, @s6intx, @arznwz`. Handles, URLs and `UC…` IDs resolve exactly for 1 unit each. Plain names are matched by YouTube search (100 units, once) and need your confirmation.
2. **Weapons**: the list starts with the MW4 Season 1 guns seen in real titles (VEL-46, X-58 NYX, M4 Hurricane, PPSh, Kastov-762, AK-74u, M4A1…). Add nicknames after a `|`, e.g. `KAR98K|KAR98`. Codes like `XM4` are auto-detected even if they aren't listed. A `weapons` list in config.json replaces the whole default list, so copy the default from core.js and edit it.
3. **Search queries**: each costs 100 units. The 10 defaults cover Resurgence, Rebirth Island, meta loadouts, SMGs, movement, controller settings, updates and challenges.

## 4. Automatic daily research and reports

The script `scripts/daily-research.mjs` does one research run and writes:

- `data/latest.json`: full verified research snapshot
- `data/history.json`: one compact snapshot per day (topic heat, weapon heat, video views), 90 days kept
- `reports/YYYY-MM-DD.md` and `reports/latest.md`: the daily report answering your 7 questions, with the research date and time

It reads its settings from `config.json`. In the dashboard, **Settings → Copy config.json for daily script** gives you a matching file. After the first run it saves resolved channel IDs back into `config.json`, so name lookups never cost quota again.

If the API fails completely, the script exits with an error and **leaves the previous data untouched**. It never writes placeholder numbers.

### Option 1: GitHub Actions (fully automatic, works while your PC is off)
1. Create a GitHub repository and push this folder.
2. **Settings → Secrets and variables → Actions → New repository secret**: name `YT_API_KEY`, value = your key.
3. The workflow `.github/workflows/daily-research.yml` runs every day at 13:07 UTC (5:07 AM Pacific in winter, 6:07 AM in summer) and commits the new data and report. Use **Actions → Daily Resurgence research → Run workflow** for an on-demand refresh.
4. Optional: **Settings → Pages → Deploy from branch (main, root)**. Your dashboard is then at `https://<you>.github.io/<repo>/` and loads each morning's research automatically, on your phone too. The API key stays a secret. Only public YouTube data is published. GitHub Pages on a private repo needs a paid plan.

### Option 2: your own computer
Create `.env` next to `package.json`:
```
YT_API_KEY=AIza...your key...
```
- **macOS / Linux (cron)**: `crontab -e`, then add
  `0 6 * * * cd /path/to/resurgence-ai && /usr/local/bin/node scripts/daily-research.mjs >> research.log 2>&1`
- **Windows (Task Scheduler)**: Create Basic Task → Daily 6:00 AM → Start a program: `node`, arguments `scripts\daily-research.mjs`, start in the project folder.

The computer has to be awake at that time. Then `npm start` and open the dashboard.

### Where history lives
- Dashboard runs: in your browser's local storage (one snapshot per day, 90 days). Use **Settings → Export** to back it up.
- Script runs: `data/history.json`, which is also merged into the dashboard when served.
- Rising / peaking / declining labels need **3+ days** of snapshots. Recent views-per-hour (the true "speed right now") needs two snapshots of the same video.
- For more than a few months of history, or several people, move snapshots into SQLite/Postgres. Every snapshot is a small JSON object, so the change is simple.

A typical run costs **~1,000–1,600 units** (10 searches = 1,000, plus ~2 per channel for baselines). That leaves room for several manual refreshes a day on the free 10,000. Quota resets at midnight Pacific. If it runs out mid-research, the app keeps what it got and tells you.

## 6. How the numbers are worked out

**Channel norm (baseline).** Median views of the channel's long-form uploads that are 7+ days old (3+ days if it uploads rarely), taken from its last 50 uploads. Shorts get their own baseline. Fetched for every tracked channel and for up to 120 channels found in search results. Only if that fails does it fall back to the channel's lifetime average, which is labelled a **weak proxy**.

**Age adjustment.** A video aged *t* days is expected to have `1 − e^(−t/4)` of a mature video's views (≈22% at 24h, 39% at 48h, 83% at 7 days). This is a tunable **assumption**, not a YouTube figure (Settings → Age adjustment).

**Breakout ratio** = views ÷ (channel norm × age adjustment). A video is flagged when the ratio is ≥ 3× (adjustable) and it has ≥ 2,000 views. Because each video is compared with **its own channel**, a big creator's normal numbers never count as viral. Example: a 5,000-view channel with a 2-day-old 30,000-view video ≈ 15× → flagged. Videos under 6 hours old are marked low confidence.

**Topics** are detected from titles: Rebirth Island, high-kill gameplay, meta loadouts, meta SMGs, meta ARs, movement, controller settings, updates, challenges, strategy, competitive. **Weapons** come from your list plus auto-detected weapon codes.

**Heat** = sum of breakout ratios (capped at 10×) for a topic's videos this week, weighted toward the last 3 days.
**Momentum** = how strongly the last 48h of uploads beat their own channels' norms, divided by the same figure for uploads from 2–7 days ago. ≥1.25 = Rising, 0.8–1.25 = Steady, below 0.8 = Cooling.
**Competition** = distinct channels that uploaded on the topic in the last 48h. **Saturated** = 8+ channels (adjustable) with momentum below 1.1, and these appear under "Avoid".

**Opportunity score (0–100)**, shown broken down on every idea:

| Part | Points | Measures |
|---|---|---|
| Momentum | 30 | Is it accelerating right now? |
| Breakout evidence | 25 | How far its best recent videos beat their channels' norms (8× = full) |
| Low competition | 20 | Few channels on it in the last 48h, i.e. early |
| Small-creator proof | 15 | Breakouts from channels ≤ 150K subs, so it works for a growing channel and not only big ones |
| Fits your channel | 10 | Your focus topics and the Resurgence share of the evidence |

Verdict: **Upload today** (score ≥ 65 and momentum ≥ 1), **Upload in 1–2 days** (≥ 50), **Wait & watch**, or **Avoid: saturated**. "Data confidence" shows how many videos the idea rests on.

**Title score (0–100)**: length 35–60 chars (15), niche keyword (15), number or weapon (15), 1–3 capitalised power words (10), uses a weapon or topic trending in today's verified data (25), word-pattern similarity to this week's breakout titles (20, reduced if it's close to a copy). These are transparent heuristics, **not** a CTR prediction.

**Limits to keep in mind.** YouTube search returns at most 50 results per query and isn't a complete census of uploads. Counts describe what your queries and tracked channels surface. Subscriber counts are rounded by YouTube, and some channels hide them. View counts can lag by a few hours.

## 6b. My ideas and Title ranker

- **My ideas** reads your idea in plain words, detects the weapon and format (movement, settings, sniper, ranked, challenge…), and scores it with the same opportunity score as the Top 10, using only videos that match it. If nobody has uploaded it this week it says **Untested** instead of inventing a score.
- **Title ranker** ranks any number of titles with the title score from section 6 and says what to improve.
- Both lists are saved in the browser you use.

**Meta shifts.** Titles like “Goodbye VEL-46, Hello X-58 NYX” are read as a weapon being replaced. The old weapon is flagged under Avoid and loses 15 points in ideas.

## 8. Extending
- **Your own channel's CTR and retention**: add Google OAuth and the YouTube Analytics API to compare your uploads with the trends.
- **LLM-written titles and ideas**: send an idea's verified evidence (titles, ratios) to an LLM API and ask for variations. Keep the evidence and the Prediction label attached.
- **Thumbnail analysis**: the thumbnail URLs are already stored with each video.
